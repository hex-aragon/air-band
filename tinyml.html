TinyML로 "내 스윙"에 맞는 드럼 고르기

TinyML은 마이크로컨트롤러(여기서는 NU40의 nRF52840) 안에서 돌아가는 아주 작은 머신러닝 모델입니다. 인터넷이나 PC 없이 보드가 직접 판단합니다.

지금 방식 (규칙) — 타격 순간 스틱이 왼쪽 25° 넘으면 하이햇, 오른쪽 25° 넘으면 탐, 위로 25° 넘으면 크래시, 나머지는 스네어.
문제: 사람마다 돌리는 각도가 달라서, 하이햇을 20°만 돌려 치는 사람은 스네어가 나옵니다. 경계 근처에서 자주 틀립니다.

TinyML 방식 — 타격 직전 0.24초 동안의 스틱 궤적(방향 6개)을 보고, 내가 직접 쳐서 모은 데이터로 학습한 작은 신경망이 드럼을 고릅니다.
내 경계와 "어디서부터 내려왔는지"를 같이 배우니 경계 근처 오판이 줄어듭니다.

전체 흐름

② 데이터드럼을 정해 놓고 20번씩 친다 → 타격마다 직전 궤적 + 정답 저장
→
③ 학습브라우저에서 신경망 학습 (1초 안팎). 규칙과 정확도 비교
→
④ 보드에 넣기zone_model.h 받기 → 펌웨어 폴더에 넣고 업로드
→
보드에서 추론타격마다 모델이 드럼 결정 (10µs 미만, 메모리 약 3KB)

모델 크기

입력방향 6개 × [좌우°, 위아래°] = 숫자 12개 (25Hz, 타격 직전 0.24초)
구조12 → 은닉 16 (ReLU) → 4 (스네어 · 하이햇 · 탐 · 크래시)
가중치276개 (float, 약 1.1KB). 펌웨어 빌드 크기 +2.7KB로 확인
킥발 동작이라 모델에서 빼고 보드 버튼 2 그대로

더 나아가기: Edge Impulse (원시 IMU로 동작 인식)

이 페이지는 이미 계산된 방향을 입력으로 씁니다. 세게/약하게, 림샷, 플램 같은 동작 자체를 구분하려면 원시 6축(가속도+자이로) 100Hz 데이터로 학습해야 하고, 그때는 Edge Impulse가 편합니다.

  1. 펌웨어 상단 DEBUG_RAW를 1로 바꿔 업로드 → 시리얼로 ax,ay,az,gx,gy,gz가 100Hz로 나옵니다.
  2. PC에서 edge-impulse-data-forwarder --frequency 100 실행 → 브라우저의 Edge Impulse 스튜디오로 데이터가 들어갑니다.
  3. 스튜디오에서 라벨 붙이기 → Spectral features + Classifier로 학습 → Arduino library로 내보내기.
  4. 펌웨어 classifyHit()에서 buf(타격 직전 0.2초 원시 샘플)를 모델에 넣으면 됩니다. 이 훅은 이미 만들어져 있습니다.

데이터 모으기

센서를 연결하고 정면 맞추기를 한 뒤, 아래에서 드럼을 고르고 그 드럼을 친다고 생각하며 스틱을 휘두르세요. 타격마다 직전 궤적이 그 드럼의 정답 데이터로 저장됩니다.

센서를 연결하세요 (보드 없이 해 보려면 아래 "가상 데이터")
가상 데이터 — 보드 없이 흐름을 익히는 용도. "하이햇을 30°쯤만 돌려 치는 사람"을 흉내 낸 데이터입니다.

모은 데이터

타격 순간 방향 (점 색 = 정답 드럼, 점선 = 규칙 경계)

점선 경계를 넘어 다른 칸에 들어간 점이 규칙이 틀리는 타격입니다. 모델은 이런 점들도 맞히도록 배웁니다.

학습

모은 데이터의 80%로 학습하고, 남은 20%(검증)로 처음 보는 타격을 얼마나 맞히는지 잽니다.

실시간 시험

센서를 연결하고 치면, 타격마다 모델의 예측과 보드 규칙의 판정을 나란히 보여 줍니다.

보드에 넣기

먼저 ③ 학습을 하세요.
  1. 받은 zone_model.h를 air-band/firmware/air_band_right/ 폴더(.ino 옆)에 넣습니다.
  2. Arduino IDE에서 평소처럼 업로드합니다. 펌웨어의 USE_TINYML이 1이면(기본값) 파일을 자동으로 찾아 씁니다.
  3. 시리얼 모니터에서 ?를 보내 상태 줄에 classifier=tinyml이 보이면 모델로 동작 중입니다.
  4. 되돌리려면 zone_model.h를 지우고 다시 업로드합니다 (classifier=rule).
// air_band_right.ino — 이미 들어가 있는 부분
uint8_t classifyHit(const SampleBuffer& buf, uint8_t peakZone) {
#if TINYML_ACTIVE                       // zone_model.h가 있으면
  float x[12];                          // 직전 방향 6개 (25Hz) [좌우, 위아래]
  ...
  return zoneModelPredict(x);           // 모델이 드럼 결정
#endif
  return peakZone;                      // 없으면 지금처럼 구역 규칙
}
아직 실제 스윙으로 검증하지 않은 기능입니다. 웹은 모션 패킷(25Hz) 6개로, 보드는 자기 기록 6개로 입력을 만들기 때문에 두 시점이 최대 40ms 어긋날 수 있습니다. 업로드한 뒤 ③의 "실시간 시험"이나 자유 연주 화면에서 드럼이 잘 맞는지 꼭 확인하고, 이상하면 데이터를 더 모아 다시 학습하세요.
